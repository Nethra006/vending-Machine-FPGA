# FPGA-Based Vending Machine Controller

A Verilog-based vending machine controller designed and implemented on the **Digilent Nexys A7 FPGA Development Board** using **Xilinx Vivado 2025.2**.

## 1. Project Overview

This project implements a digital vending machine controller using Verilog HDL. The system accepts ₹5 and ₹10 coin inputs and allows users to select between two products with different prices.

The controller checks the accumulated amount, dispenses the selected product when sufficient money is available, and indicates the applicable change through output LEDs.

The design was synthesized, implemented, and tested using the Nexys A7 FPGA development board.

## 2. Objectives

- Design a vending machine controller using Verilog HDL.
- Accept ₹5 and ₹10 coin inputs.
- Provide two product selection options.
- Check whether the inserted amount is sufficient.
- Generate product dispensing and change indication outputs.
- Implement and test the design on an FPGA board.

## 4. Working Principle

The vending machine operates based on the amount of money inserted by the user.

1. The user inserts either a ₹5 or ₹10 coin using the input switches.
2. The controller updates the accumulated amount.
3. The user selects Product A or Product B.
4. The controller checks whether the accumulated amount is sufficient.
5. If the amount is sufficient, the corresponding product dispensing output is activated.
6. The change indication output is activated according to the remaining amount.
7. The accumulated amount is reset after a successful product selection.

### Product Details

| Product | Price |
|---|---:|
| Product A | ₹10 |
| Product B | ₹15 |

### Output Indications

| Output | Function |
|---|---|
| dispense_A | Indicates dispensing of Product A |
| dispense_B | Indicates dispensing of Product B |
| change_5 | Indicates ₹5 change |
| change_10 | Indicates ₹10 or more change |

The output signals are generated as one-clock-cycle pulses.

## 5. Hardware Implementation

The design was implemented on the **Digilent Nexys A7 Artix-7 FPGA Development Board**.

The board switches are used to provide coin inputs and product selection signals. The center push button is used for reset, while four LEDs indicate product dispensing and change outputs.

### FPGA Pin Mapping

| Signal | FPGA Pin | Board Component |
|---|---|---|
| clk | E3 | 100 MHz Clock |
| coin5 | J15 | SW0 |
| coin10 | L16 | SW1 |
| select_A | M13 | SW2 |
| select_B | R15 | SW3 |
| reset | U18 | BTNC |
| dispense_A | H17 | LED0 |
| dispense_B | K15 | LED1 |
| change_5 | J13 | LED2 |
| change_10 | N14 | LED3 |

All I/O pins use the LVCMOS33 standard.

## 6. Design and Implementation Flow

The project was developed using the following workflow:

1. Verilog RTL design of the vending machine controller.
2. Creation and configuration of the Vivado project.
3. Addition of the XDC constraints file.
4. RTL synthesis.
5. Design implementation and placement.
6. Routing and timing analysis.
7. Bitstream generation.
8. FPGA hardware programming and testing.
